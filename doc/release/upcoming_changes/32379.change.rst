``numpy.generic.astype`` honours ``copy=False``
-----------------------------------------------
Like ``ndarray.astype``, the scalar method now returns its input unchanged
when ``copy=False`` is given and ``dtype`` matches the scalar's own data
type (``numpy.void`` excepted).  The default ``copy=True`` still returns a
new scalar.  As a side effect, ``scalar.astype(scalar.dtype)`` is several
times faster.
