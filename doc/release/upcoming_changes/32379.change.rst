``numpy.generic.astype`` may return the scalar itself
-----------------------------------------------------
NumPy scalars other than ``numpy.void`` are immutable, so
``scalar.astype(dtype)`` and ``scalar.astype(dtype, copy=False)`` now return
the scalar itself when ``dtype`` is its own data type, which is several times
faster.  This is an optimization and not guaranteed: other cases (e.g.
``dtype`` passed as a keyword, or string and datetime scalars) may still
return a new scalar, and an explicit ``copy=True`` still makes a copy.
